# 오르내림 · 스쿼트 반복 관찰

정면 스마트폰 영상 한 편을 브라우저 안에서 처리해 스쿼트 반복별 무릎 간격과 골반 높이 변화를 근거 장면과 함께 보여 주는 정적 웹서비스입니다. 관련 부위 스트레칭 콘텐츠와 함께 해볼 하지 운동을 국민체력100 영상으로 제공하고, 같은 조건으로 한 세트를 더 촬영하면 직전 세트와 변화 방향을 비교합니다.

**서비스:** https://minsoo5013.github.io/squat-observer/

## 이용 방법

1. `혼자 촬영`, `다른 사람이 촬영`, `기존 영상 업로드` 중 한 가지를 고릅니다. 혼자 촬영은 전면 카메라와 자동 시작·종료를, 다른 사람이 촬영할 때는 전면·후면 카메라와 수동 버튼을 사용합니다.
2. 혼자 촬영에서는 전신과 정지 상태를 확인하면 3초 뒤 자동으로 녹화를 시작합니다. 화면 아래 상태 띠와 짧은 효과음에 따라 시작하고, 8회(최소 6회)를 수행한 뒤 제자리에서 2초 서면 촬영을 마칩니다. 촬영 중 횟수는 진행용 추정이며 최종 횟수는 분석 결과에서 확인합니다.
3. 회차별 무릎 간격과 골반 높이를 주 그래프로 보고, 상체 숙임·반복 시간은 참고 그래프로 확인합니다. 모든 저점 장면과 선택한 회차는 세트 중앙값에 가까운 회차와 나란히 볼 수 있습니다.
4. 결과 아래에서 관련 부위 스트레칭 콘텐츠와 모든 결과에 공통으로 표시되는 `함께 해볼 하지 운동`을 확인할 수 있습니다.
5. 같은 조건으로 한 세트를 더 하면 직전 세트와 무릎 간격·골반 높이를 비교합니다.

영상, 프레임, 관절 좌표는 서버로 전송하지 않습니다. 분석은 브라우저 안에서 MediaPipe Pose Landmarker와 Pyodide를 이용해 실행합니다.

기존 영상을 올릴 때는 앞뒤로 걸어가거나 휴대폰을 만지는 부분을 잘라 주세요. 모바일 선택창은 `capture` 속성을 강제하지 않으며, 브라우저에서 재생 가능한 90초 이하 MP4/H.264를 권장합니다.

이 서비스는 정면 영상에서 관찰되는 반복 사이의 변화를 보여 주며 의료 진단이나 원인 판정을 제공하지 않습니다.
